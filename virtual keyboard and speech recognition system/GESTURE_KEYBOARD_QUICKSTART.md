# Hand Gesture Virtual Keyboard - Quick Start Guide

## 🚀 Get Started in 30 Seconds

### Step 1: Launch
Open command prompt in the project directory and run:
```bash
python launch_gesture_keyboard.py
```

### Step 2: Click Launch
When the interface appears, click the **"🎥 Launch Keyboard"** button

### Step 3: Use Your Hand
1. Position your hand in front of the camera (visible in left panel)
2. Point your **index finger** at the key you want
3. **Close your fist** to click the key
4. Watch your text appear in the display field

## 📝 Quick Reference

| Action | Gesture |
|--------|---------|
| **Select Key** | Point index finger |
| **Click Key** | Close hand into fist |
| **Space** | Point at "Space" key + fist |
| **Delete** | Point at "Back" key + fist |
| **Finish** | Point at "Enter" key + fist |

## ⚙️ System Requirements
- ✓ Webcam or built-in camera
- ✓ Python 3.7+
- ✓ Dependencies installed (`pip install -r requirements.txt`)

## 🎯 Success Tips
1. **Lighting**: Good lighting helps hand detection
2. **Distance**: Sit 60-80cm from camera
3. **Full Hand**: Keep entire hand visible
4. **Clear Fist**: Close fingers completely for clicks
5. **Steady Pointing**: Hold finger position when selecting keys

## ❓ Having Issues?

### Camera not detected?
- Make sure webcam is connected
- Close other camera applications
- Try clicking "Retry" in settings

### Hand not showing?
- Improve room lighting
- Position hand clearly in front of camera
- Move closer (60-80cm optimal)

### Keys not clicking?
- Make a fuller fist (curl all fingers)
- Pause between clicking motions
- Check hand is visible in camera feed

## 💡 Pro Tips
- **Typing Speed**: Start slow, practice builds speed
- **Comfort**: Take breaks if arm gets tired
- **Accuracy**: Point clearly at keys before closing fist
- **Text Editing**: Use "Back" button to delete mistakes
